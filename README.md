# biomedical-data-analysis
A portfolio of hands-on biomedical data analysis projects using Python, with a focus on data exploration, visualization, and reproducible research.

## Objectives
- Strengthen practical Python and data analysis skills
- Explore real-world biomedical datasets
- Document analytical methods, findings, and limitations
- Build reproducible research projects

## Tools
Python | Pandas | NumPy | Matplotlib | Jupyter Notebook
